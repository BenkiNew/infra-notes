# Як запропонувати виправлення

Пишіть українською або англійською.

Для неточності наведіть посилання на розділ, поясніть проблему та додайте джерело або мінімальний приклад. Для зміни в pull request достатньо короткого опису: що виправлено і як перевірено.

Надсилайте лише матеріали, які можна публікувати. Використовуйте вигадані імена, адреси й дані. Не додавайте токени, приватні журнали, дампи, core dumps або production-конфігурації з доступами.

Непідтверджені припущення позначайте явно. Відрізняйте спостереження від пояснення причини.

Discussions призначені для справжніх запитань і обміну досвідом. Прийнята відповідь має розв'язувати запитання автора обговорення.
